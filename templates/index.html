Direct Integration REST API

Integrate our trained ML scoring engine directly into your banking applications and loan origination software.

POST /api/predict

Pass applicant payload as JSON to receive instant binary approval classification and probability confidence.

Sample cURL Request

curl -X POST http://localhost:5050/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "model_type": "lr",
    "Gender": "Male",
    "Married": "Yes",
    "Dependents": "0",
    "Education": "Graduate",
    "Self_Employed": "No",
    "ApplicantIncome": 5849,
    "CoapplicantIncome": 0,
    "LoanAmount": 128,
    "Loan_Amount_Term": 360,
    "Credit_History": 1.0,
    "Property_Area": "Semiurban"
  }'
